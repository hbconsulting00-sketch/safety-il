## סקירה כללית

SafetyIL הוא עוזר AI המתמחה בבטיחות תעסוקתית בישראל. המערכת משתמשת במודל **Gemini 2.5 Flash** של Google ומכילה system prompt מובנה הכולל את מלוא החקיקה הישראלית הרלוונטית לבטיחות בעבודה.

המשתמש בוחר את תפקידו (עובד, מנהל, ממונה בטיחות, קבלן) — ובהתאם מותאמת רמת הפירוט, השפה, והדגשים בכל תשובה.

## יכולות עיקריות

### שיחה והתאמה אישית
- **שיחה רציפה** — זיכרון של 8 הודעות אחרונות לשמירת הקשר
- **ארבעה תפקידים** — תשובות מותאמות לעובד, מנהל עבודה, ממונה בטיחות, וקבלן
- **שאלות נפוצות מהירות** — 6 כפתורי קיצור לשאלות שכיחות
- **שאלות הבהרה** — כשהשאלה מעורפלת, המערכת שואלת שאלת הבהרה אחת לפני תשובה

### איכות תשובות
- **הפניות חקיקתיות מדויקות** — שם תקנה + מספר סעיף + תת-סעיף + שנה לכל טענה
- **סיווג משפטי אוטומטי** — כל פריט מסומן: `חובה חוקית` / `המלצה מקצועית` / `אסור לפי חוק`
- **פעולה נדרשת** — בסוף כל תשובה מופיעים צעדים מעשיים לביצוע
- **מצב סכנה מיידית** — הדגשה בולטת בראש התשובה כשיש סכנה לחיים
- **ציות לחקיקה בלבד** — אם אין מידע בחקיקה, המערכת מציינת זאת במפורש

### מסמכים ועיבוד
- **העלאת מסמכי חברה** — תמיכה ב-PDF, Word ו-TXT לנהלים פנימיים
- **גרירה ושחרור** — drag & drop לאזור ההעלאה
- **עד 10 קבצים** — בו-זמנית, עד 10MB לכל קובץ

### ממשק
- **ממשק RTL עברי** — עיצוב מלא בעברית, מימין לשמאל
- **עיצוב כהה** (dark mode) עם ערכת צבעים navy/gold
- **אינדיקטור חיבור** — בדיקת חיבור לשרת בטעינה
- **אנימציית הקלדה** — טעינה חיה בזמן המתנה לתשובה

## התקנה והפעלה

```bash

cd safety-il
```

### שלב 2 — התקן תלויות

```bash

```

```bash
cp .env.example .env
```


## ארכיטקטורה

```
דפדפן (public/index.html)
        │
        │  POST /api/chat   { system, messages[], max_tokens }
        │  POST /api/upload { files[] }
        │  GET  /           הגשת ה-HTML
        ▼
שרת Node.js (server.js) — proxy בלבד, מפתח API נשמר בשרת
        │
        │  POST https://generativelanguage.googleapis.com/v1beta/
        │       models/gemini-2.5-flash:generateContent?key=...
        ▼
Google Gemini API
```

### זרימת שיחה

1. המשתמש בוחר תפקיד (עובד / מנהל / ממונה / קבלן)
2. המשתמש מקליד שאלה או לוחץ על כפתור שאלה מהירה
3. הלקוח בונה בקשה: `system prompt` + הוראות תפקיד + קבצים שהועלו + היסטוריה (8 הודעות אחרונות)
4. השרת מעביר את הבקשה ל-Gemini API
5. Gemini מחזיר HTML מובנה עם תגיות סיווג ומקורות
6. הלקוח מריץ `sanitizeHtml()` ומציג את התוצאה

### ניהול שיחה בלקוח

```javascript
conversation = [
  { role: 'user',      content: '...' },
  { role: 'assistant', content: '...' },  // stripped HTML → טקסט
  ...
]
// נשלחות רק 8 ההודעות האחרונות בכל פנייה
```

## העלאת נהלי חברה

ניתן להעלות נהלי בטיחות פנימיים של החברה — הם יתווספו ל-context ויילקחו בחשבון בתשובות.

### כיצד להעלות

1. לחץ על אזור **"העלה נהלי חברה"** בסרגל הצד השמאלי
2. בחר קובץ (או גרור ושחרר)
3. הקבצים מופיעים תחת **"מסמכי חברה"** בסרגל ויוסרו עם רענון הדף

### מגבלות

| פורמט | עיבוד תוכן |
|--------|------------|
| `.txt` | קריאה מלאה (עד 12,000 תווים ראשונים) |
| `.pdf` | שם + גודל בלבד (נדרשת ספריית pdf-parse לחילוץ מלא) |
| `.doc` / `.docx` | שם + גודל בלבד (נדרשת ספריית mammoth לחילוץ מלא) |

- עד 10 קבצים בו-זמנית
- עד 10MB לכל קובץ

## API Reference

### `POST /api/chat`

שליחת הודעה ל-Gemini דרך הפרוקסי.

**בקשה:**
```json
{
  "messages": [
    { "role": "user",      "content": "טקסט השאלה" },
    { "role": "assistant", "content": "תשובה קודמת" }
  ],
  "system": "system prompt כולל הוראות תפקיד",
  "max_tokens": 4000
}
```

**תגובה מוצלחת:**
```json
{ "text": "<h3 ...>תשובה בפורמט HTML</h3>..." }
```

**תגובת שגיאה:**
```json
{ "error": "תיאור השגיאה" }
```

---

### `POST /api/upload`

העלאת קבצי נהלים.

**בקשה:** `multipart/form-data` עם שדה `files[]`

**תגובה:**
```json
{
  "files": [
    { "name": "נוהל_בטיחות.txt", "content": "תוכן הקובץ...", "size": 2048 }
  ]
}
```

---

### `GET /`

הגשת ממשק המשתמש (`public/index.html`).

## אבטחה

- **מפתח API בשרת בלבד** — הדפדפן אינו נחשף לו לעולם
- **sanitizeHtml בלקוח** — HTML מהשרת מנוקה לפני הצגה (מסיר `<script>`, `<style>`, event handlers, `javascript:`)
- **קבצים שהועלו** — נשמרים ב-`uploads/` בלבד, לא נגישים דרך ה-web
- **`.gitignore`** — מוגדר לא לכלול `.env` ו-`uploads/`
- **CORS** — מופעל לכל המקורות (מתאים לפיתוח; להגביל ב-production)

## הגבלות ואחריות
